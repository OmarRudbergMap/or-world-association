Chaque page affiche son numéro de version en bas à droite.
Après un Push, c'est ce numéro qui vous dit si la mise en ligne a fonctionné.

## Mettre en ligne, étape par étape

1. Copiez TOUT le contenu de ce dossier dans le dossier du dépôt GitHub
   (celui que GitHub Desktop a créé lors du Clone).
2. Ouvrez GitHub Desktop : les fichiers apparaissent à gauche.
3. En bas à gauche, écrivez un résumé, par exemple « Première version du site ».
4. Cliquez sur **Commit to main**, puis sur **Push origin** en haut.
5. Sur github.com, dans le dépôt : **Settings → Pages**.
   Source : **Deploy from a branch** · Branch : **main** · Dossier : **/ (root)** · Save.
6. Attendez deux à trois minutes, puis ouvrez l'adresse indiquée par GitHub.

## Ensuite, à chaque modification

Pull (avant de commencer) → modifications → Commit → Push → vérifier le numéro de version.

## Ce qui ne fonctionne pas encore

Ces éléments sont visuels pour l'instant ; ils s'animeront quand Supabase,
Stripe et PayPal seront branchés :

- création de compte, connexion, espace membre
- paiement de l'adhésion et commandes de la boutique
- envoi des histoires, des projets, des photos et des articles
- compteurs (ils affichent zéro)
- e-mails automatiques et factures

## Rappel important

Aucune clé secrète ne doit jamais être placée dans ce dossier : il est public.
Les clés vivent dans Supabase et dans votre gestionnaire de mots de passe.
